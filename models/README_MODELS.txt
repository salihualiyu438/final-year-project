MODEL WEIGHTS OMITTED

This ZIP intentionally excludes model weight files to reduce download size.

Place your trained weights in the models directory using these filenames:
- model1.pt
- model2.pt

If the optional segmentation feature is enabled and requires YOLO segmentation weights, place the appropriate segmentation weight file at the path expected by your configuration. The original yolo11n-seg.pt file is not included.

Ensure model class names match your trained weights, especially the exact threat class `matchet/knife`.
